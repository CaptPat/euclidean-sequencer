# Euclidean Sequencer

A multi-track Euclidean rhythm sequencer in a single, dependency-free HTML file. It uses the Bjorklund algorithm, Web Audio synthesized drums, polyrhythmic track lengths, rotary knobs and presets (tresillo, dembow, cinquillo, bossa clave, bembé, and more).

**Live:** https://captpat.github.io/euclidean-sequencer/

Press **Space** to play or stop. Drag the knobs (or use the mouse wheel) to change HITS, STEPS and ROTATE. Click a step to toggle it.

Inspired by the "Claudia Explains: Euclid" video by [@anabology](https://x.com/anabology) on X.
